# RetailIQ Performance Dashboard

This directory contains the Power BI reporting assets for Apex Retail Corporation.

## 📊 Overview
The dashboard directly connects to the PostgreSQL data warehouse to provide real-time insights into retail operations, inventory efficiency, and supplier performance.

## 📱 Page Structure
1. **Executive Summary**: High-level Overview of Net Revenue, AOV, Gross Margin %, and Regional Performance.
2. **Inventory & ROP Analytics**: Stock levels, Reorder Point (ROP) alerts, and Turnover rates across warehouses.
3. **Supplier & OTIF Performance**: On-Time In-Full (OTIF) compliance rates and return analysis.
